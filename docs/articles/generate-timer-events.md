# Generate timer events

Besides the [heartbeat](./set-clock.md) event, the Timestamp Generator Gen3 can also report a high-frequency counter (50–1000 Hz). Each counter event carries an incrementing value timestamped with the device clock, which is useful for inspecting the clock and detecting dropped messages. The counter can also assign Harp timestamps to data that are not generated by Harp devices, such as software events, placing them on the same timeline.

This article covers how to enable the timer events, visualize them, set the counter value, and timestamp software events in Bonsai.

The complete workflow is shown below. Copy and paste it into Bonsai to get started immediately, or build each section by following the step-by-step instructions in the following sections.

:::workflow
![Generate timer events](../workflows/generatetimerevents-toplevel.bonsai)
:::

> [!WARNING]
> Unlike the [Set clock](set-clock.md) article, these workflows use the device-specific versions of the operators, e.g. `Device (Harp.TimestampGeneratorGen3)` instead of `Device (Harp)`. If correctly selected, the names of these operators in the workflow panel will change to reflect either the name of the device or the selected register/payload.

## Enable timer events

The counter is disabled by default, so it must be enabled with the [`TimerFrequency`] register before any events are reported.

:::workflow
![Enable timer events](../workflows/generatetimerevents-frequency.bonsai)
:::

- Insert a [`KeyDown`] operator and set the `Filter` property to `A`.
- Insert a [`CreateMessage`] operator and configure the following properties:
    - `Payload` - Select `TimerFrequencyPayload`.
    - `TimerFrequency` - Select the event frequency (e.g. `Timer50Hz` to generate 50 events per second). To disable the events in the future, select `Disabled`.
- Insert a [`MulticastSubject`] operator named `TimestampGeneratorGen3 Commands`.

Run the workflow and press <kbd>A</kbd>. The device starts reporting [`Timer`] events at 50 Hz (covered in the next section).

## Visualize timer events

Each [`Timer`] event carries the current counter value and the timestamp at which it was generated. The workflow below will show you how to decode and visualize the timer events:

:::workflow
![Visualize timer events](../workflows/generatetimerevents-events.bonsai)
:::

- Insert a [`SubscribeSubject`] operator named `TimestampGeneratorGen3 Events`.
- Insert a [`Parse`] operator and set the `Register` property to `TimestampedTimer`.
- Insert a [`VisualizerWindow`] operator. This will automatically open a visualizer displaying the parsed events when the workflow starts.

Run the workflow and press <kbd>A</kbd> to enable the counter. The visualizer will display:

```text
4778@95.563344
4779@95.583344
```

The first number is the counter value, and the second number is the timestamp on the device clock.

## Set counter value

Writing to the [`Timer`] register sets the value of the counter. This is useful for resetting the counter to zero at the start of a session.

:::workflow
![Set counter value](../workflows/generatetimerevents-counter.bonsai)
:::

- Insert a [`KeyDown`] operator and set the `Filter` property to `S`.
- Insert a [`CreateMessage`] operator and configure the following properties:
    - `Payload` - Select `TimerPayload`.
    - `Timer` - Enter `0` to reset the counter.
- Insert a [`MulticastSubject`] operator named `TimestampGeneratorGen3 Commands`.

Run the workflow and press <kbd>S</kbd>. The counter value in the visualizer window resets to zero.

> [!TIP]
> To reset the onboard clock that timestamps the events, see the [Set clock](set-clock.md) article.

## Timestamp software events

Software events, such as key presses, can be assigned Harp timestamps by pairing them with the latest [`Timer`] event.

:::workflow
![Timestamp software events](../workflows/generatetimerevents-softwareevents.bonsai)
:::

- Insert a [`KeyDown`] operator and set the `Filter` property to `D`. This is the software event that will be timestamped.
- Insert a [`WithLatestFrom`] operator.

In a separate branch:

- Insert a [`SubscribeSubject`] operator named `TimestampGeneratorGen3 Events`.
- Insert a [`Parse`] operator and set the `Register` property to `TimestampedTimer`.

To combine the two branches:

- Connect the [`Parse`] operator to the [`WithLatestFrom`]. Each key press will now be paired with the latest [`Timer`] event.
- Insert a [`VisualizerWindow`] operator to display the paired events.

Run the workflow and press <kbd>D</kbd>. Each key press appears in the visualizer window paired with the latest timestamped counter value:

```text
(D, 141404@19990.36)
(D, 146440@20000.66)
```

> [!NOTE]
> The timestamp resolution with this strategy is set by the [`TimerFrequency`] (e.g. 20 ms at 50 Hz). Use a higher frequency for finer resolution. Keep in mind, however, that Windows is not a real-time operating system, so software timestamping is not ideal for high-precision timing applications.
